Cinema-Grade HTML5 Overlay

Introduction to YVPlayer

YVPlayer is a high-performance, distraction-free HTML5 video player overlay designed specifically for YouTube videos. It strips away 100% of YouTube's native interface clutter, including video titles, channel avatars, "More videos" recommended drawers, and end-screen cards, while elevating playback with cinema-grade features inspired by modern production players like Video.js 10.

Zero AI Slop Guarantee

YVPlayer is handcrafted in pure vanilla ES6 JavaScript and clean modern CSS with zero heavy framework dependencies. Every animation uses GPU-accelerated cubic-bezier curves, every layout is mathematically locked to 16:9, and every theme dynamically recalculates CSS custom property tokens in real-time.

Quick Start: Embed in 3 Simple Steps (Under 60 Seconds)

No complicated setups or bundler configurations required:

  1. Step 1: Include the CSS & JS links in your <head>.
  2. Step 2: Place <div data-yv-video="YOUR_VIDEO_ID" style="aspect-ratio:16/9;"></div> anywhere on your page.
  3. Step 3: That is it! The player automatically initializes with custom controls, themes, and scrubbing.

Framework Integration

React & Next.js Component

Integrate YVPlayer into React 18, React 19, or Next.js (App Router / Pages Router) with proper mounting, unmounting, and memory leak cleanup:

React / Next.js — VideoPlayer.tsx 
import React, { useEffect, useRef } from "react";

export function VideoPlayer({ videoId, theme = "red", customColor, autoplay = true }) {
  const containerRef = useRef(null);
  const playerIdRef = useRef("yv-" + Math.random().toString(36).substring(2, 9));

  useEffect(() => {
    const id = playerIdRef.current;
    if (typeof window === "undefined" || !window.YVPlayer) return;

    window.YVPlayer.init(id, {
      defaultId: videoId,
      theme,
      autoplay
    }).then(() => {
      if (customColor) window.YVPlayer.setTheme(id, customColor, "Custom");
    });

    return () => {
      if (window.YVPlayer?.destroy) window.YVPlayer.destroy(id);
    };
  }, [videoId, theme, customColor, autoplay]);

  return (
    <div
      id={playerIdRef.current}
      ref={containerRef}
      style={{ maxWidth: "960px", aspectRatio: "16/9", borderRadius: "14px", overflow: "hidden" }}
    />
  );
}

Vue 3 (Composition API & <script setup>)

Drop the following reusable Single File Component (SFC) into your Vue 3 or Vite project. It automatically synchronizes video IDs, themes, and PiP modes with full reactive watchers:

Vue 3 Component — YVPlayer.vue 
<template>
  <div
    :id="playerId"
    class="yvPlayer"
    :style="{ width: '100%', aspectRatio: '16 / 9', borderRadius: radius, overflow: 'hidden' }"
  ></div>
</template>

<script setup>
import { ref, onMounted, onBeforeUnmount, watch } from "vue";

const props = defineProps({
  videoId: { type: String, required: true },
  theme: { type: String, default: "red" },
  customColor: { type: String, default: null },
  autoplay: { type: Boolean, default: true },
  pipMode: { type: String, default: "document" },
  radius: { type: String, default: "14px" }
});

const playerId = "yv-" + Math.random().toString(36).substring(2, 9);

onMounted(() => {
  if (typeof window === "undefined" || !window.YVPlayer) return;

  window.YVPlayer.init(playerId, {
    defaultId: props.videoId,
    theme: props.theme,
    customColor: props.customColor,
    autoplay: props.autoplay,
    pipMode: props.pipMode,
    storyboard: true
  });
});

watch(() => props.videoId, (newId) => {
  if (window.YVPlayer && window.YVPlayer.changeVideo) {
    window.YVPlayer.changeVideo(playerId, newId);
  }
});

watch(() => props.theme, (newTheme) => {
  if (window.YVPlayer && window.YVPlayer.setTheme) {
    window.YVPlayer.setTheme(playerId, props.customColor || newTheme, newTheme);
  }
});

onBeforeUnmount(() => {
  if (window.YVPlayer && window.YVPlayer.destroy) {
    window.YVPlayer.destroy(playerId);
  }
});
</script>
Nuxt 3 SSR Note: Wrap your player component in <ClientOnly> to ensure client-side DOM evaluation since YVPlayer operates on browser window objects and the YouTube IFrame API.

Events, State & Callbacks

Monitor player lifecycle transitions, real-time playback milestones, volume adjustments, and Picture-in-Picture handoffs using YVPlayer's unified event listener engine.

Playback State Constants

YVPlayer normalizes YouTube playback states into standard string identifiers and numeric constants accessible via YVPlayer.getState(videoTag):

Code State Constant Lifecycle Description Controls UI Appearance
-1 unstarted Player initialized with video metadata; waiting for play trigger. Large frosted center play button visible; poster thumbnail shown.
1 playing Video actively decoding and playing audio/video frames. Controls auto-fade after 3s; center pause icon on hover; seekbar glowing.
2 paused Playback halted by user, sleep timer, or window blur. Controls persistently visible; center play icon displayed.
3 buffering Network fetching stream chunks or seeking to a new timestamp. Smooth pulsating spinner displayed at the center of the video stage.

Subscribing to Events

Use YVPlayer.on(videoTag, eventName, handler) to listen for real-time player actions. Remove listeners via YVPlayer.off():

JavaScript — Event Subscription 
// 1. Listen for playback start
YVPlayer.on("my-player", "play", () => {
  console.log("Playback started or resumed");
});

// 2. High-frequency timeline updates (every 250ms)
YVPlayer.on("my-player", "timeupdate", ({ currentTime, duration, progress }) => {
  console.log(`Current: ${currentTime.toFixed(1)}s / ${duration.toFixed(1)}s (${progress.toFixed(1)}%)`);
});

// 3. Picture-in-Picture mode activation
YVPlayer.on("my-player", "pipenter", ({ mode }) => {
  console.log(`Entered PiP mode: ${mode}`); // "document", "os", or "inpage"
});

// 4. Picture-in-Picture window closed
YVPlayer.on("my-player", "pipexit", () => {
  console.log("Returned to on-page player stage");
});

// 5. Volume or mute toggle
YVPlayer.on("my-player", "volumechange", ({ volume, isMuted }) => {
  console.log(`Volume: ${volume}%, Muted: ${isMuted}`);
});

// 6. Theme accent color change
YVPlayer.on("my-player", "themechange", ({ color, theme }) => {
  console.log(`Switched to theme ${theme} (${color})`);
});

Triple-Engine Picture-in-Picture (PiP) Architecture

Unlike ordinary video players that restrict users to basic OS video windows without controls, YVPlayer provides three distinct, independent Picture-in-Picture architectures engineered for every browser capability, operating system, and deployment workflow.

Architecture Highlights: Document PiP pops out the complete interactive HTML DOM (with scrubbing thumbnails and themes) into an OS desktop window; Native Video PiP provides hardware-accelerated 720p streaming with live subtitles and OS media keys; and In-Page Dock delivers 100% universal compatibility with 4-corner aspect-locked resizing.
ENGINE A — MODERN W3C STANDARD

Document Picture-in-Picture (Full Desktop OS Window)

Chrome 116+ — Edge 116+ — Opera data-yv-pip="document"

Pops out the entire rich YVPlayer DOM into an independent, always-on-top desktop operating system window using window.documentPictureInPicture.requestWindow(). All custom controls, storyboard scrubbing, audio sliders, and theme accents continue running smoothly outside the browser tab.

100% Custom UI & Theming Preserved Custom seekbar track, glowing thumbs, volume pills, sleep countdown badge, and storyboard preview tooltips render natively inside the floating window.
Zero-Crop Letterboxing & Aspect Guard Preserves 100% of the video canvas with zero cropping. When resized to non-16:9 aspect ratios, cinema-grade letterboxing and pillarboxing with pure black borders automatically adapt to any window dimensions.
State Handoff & Zero-Frame Snap Return The host webpage displays an elegant frosted "Playing in OS Window" placeholder with a single-click return button. Closing the OS window instantly snaps video playback back into the webpage with zero dropped frames.
Zero Proxy Requirement Document PiP operates directly on the client DOM without requiring a backend stream proxy or serverless workers.

Native Hardware Video PiP (Hardware OS Streaming)

Universal Desktop OS — Chrome, Edge, Safari, Firefox data-yv-pip="os"

Leverages the W3C standard HTMLVideoElement.requestPictureInPicture() specification by streaming clean, direct 720p HD MP4 (YouTube Format 22) through the Cloudflare Worker or Python edge proxy. Delivers full OS-level hardware-accelerated playback with native operating system controls.

Live WebVTT Subtitle Shipping Dynamically injects timed VTTCue objects into the native video element's TextTrack. Captions render crisp, clean subtitles directly inside the floating OS Picture-in-Picture window.
Synchronized Host Stage Control Bar While playing in the floating OS window, the main on-page player remains fully synchronized with an interactive scrubber bar, time counter, volume slider, and "Exit picture-in-picture" pill.
Unmuted Volume & OS Media Keys Audio streams unmuted by default with smooth OS volume slider integration, keyboard shortcuts (↑, ↓, M), and hardware media play/pause keys.
Edge Stream Proxy Integration Connects seamlessly with the bundled serverless Cloudflare Worker or self-hosted Python proxy with automatic format resolution and in-memory URL caching.

Frame-Accurate Storyboard Scrubbing

YVPlayer extracts YouTube timeline mosaic sheets to deliver instant, zero-latency visual thumbnail previews on hover without downloading video frames or consuming heavy streaming bandwidth.

How YouTube Storyboards Work

YouTube encodes video previews into compressed JPEG mosaic sheets (e.g. 5x5 or 10x10 grids of frames captured at strict intervals like every 2 or 5 seconds). YVPlayer parses the video's storyboard_spec, computes the precise row and column coordinate for any cursor position along the timeline, and positions the preview via CSS background offsets:

Mosaic Variable Standard Value Mathematical Role in Sprite Calculations
cols ($N_{\text{cols}}$) 5 (or 10) Number of horizontal frame tiles across a single JPEG sheet.
rows ($N_{\text{rows}}$) 5 (or 10) Number of vertical frame tiles down a single JPEG sheet.
width ($W$) 160px Exact pixel width of each individual 16:9 thumbnail frame tile.
height ($H$) 90px Exact pixel height of each individual 16:9 thumbnail frame tile.
interval ($\Delta t$) 2.0s (or 5.0s) Seconds of video playback represented between consecutive thumbnail frames.

Sprite Coordinate Math & Offset Formula

Given total duration $D$, cursor hover ratio $R \in [0, 1]$, and hover timestamp $T = R \times D$:

Mathematical Algorithm — Background Position Offset 
// 1. Calculate overall tile index
const tileIndex = Math.floor(hoverTime / interval);
const tilesPerSheet = cols * rows;

// 2. Determine target mosaic sheet number
const sheetIndex = Math.floor(tileIndex / tilesPerSheet);

// 3. Determine exact column and row coordinates
const indexInSheet = tileIndex % tilesPerSheet;
const col = indexInSheet % cols;
const row = Math.floor(indexInSheet / cols);

// 4. Apply CSS background position offset
tooltipImg.style.backgroundImage = `url(${sheetUrl.replace("$M", sheetIndex)})`;
tooltipImg.style.backgroundPosition = `-${col * tileWidth}px -${row * tileHeight}px`;

Boundary Edge Clamping

To prevent the hover tooltip from clipping past the left or right edge of the video stage, YVPlayer implements sub-pixel boundary clamping:

Boundary Clamping Algorithm 
// Keep tooltip center point strictly within [halfTooltip, stageWidth - halfTooltip]
const halfTooltip = tooltipWidth / 2;
const clampedX = Math.max(halfTooltip, Math.min(cursorX, stageWidth - halfTooltip));

Cloudflare Worker Proxy (Serverless)

Deploy your stream resolver on Cloudflare Workers for global edge delivery with $0 server maintenance costs and ultra-low latency. Below is the complete production script:

JavaScript — worker.js (Cloudflare Workers) 
// ============================================================
// Cloudflare Worker: YouTube Stream & Storyboard Edge Proxy
// ============================================================
export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);

    // Handle CORS preflight
    if (request.method === "OPTIONS") {
      return new Response(null, {
        headers: {
          "Access-Control-Allow-Origin": "*",
          "Access-Control-Allow-Methods": "GET, HEAD, OPTIONS",
          "Access-Control-Allow-Headers": "Range, Content-Type",
          "Access-Control-Max-Age": "86400"
        }
      });
    }

    const videoId = url.searchParams.get("id");
    if (!videoId || !/^[a-zA-Z0-9_-]{11}$/.test(videoId)) {
      return new Response(JSON.stringify({ success: false, error: "Invalid video ID" }), {
        status: 400,
        headers: { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*" }
      });
    }

    // Proxy Range requests to raw YouTube streams
    if (url.pathname === "/api/stream") {
      const clientRange = request.headers.get("Range");
      const headers = new Headers({
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/147.0.0.0 Safari/537.36"
      });
      if (clientRange) headers.set("Range", clientRange);

      const upstream = await fetch(streamUrl, { headers });
      const respHeaders = new Headers(upstream.headers);
      respHeaders.set("Access-Control-Allow-Origin", "*");
      return new Response(upstream.body, { status: upstream.status, headers: respHeaders });
    }
  }
};

Security

Security, XSS Defense & CSP Guidelines

YVPlayer follows strict defensive design patterns to guarantee safety when embedding in multi-tenant or enterprise environments:

Strict Video ID Validation: All entry points validate IDs against ^[a-zA-Z0-9_-]{11}$ to prevent command flag injection, path traversal, or SSRF attacks.
XSS-Proof Caption Rendering: Captions are injected via .textContent rather than innerHTML, ensuring external WebVTT/SRT text cannot execute arbitrary script payloads.
Strict postMessage Target Origin: All communication to YouTube iframes specifies "https://www.youtube.com" as the target origin rather than wildcard "*".
Recommended Content Security Policy (CSP):
default-src 'self'; script-src 'self' https://www.youtube.com https://cdn.jsdelivr.net; frame-src https://www.youtube.com; media-src 'self' blob:; style-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net https://fonts.googleapis.com; font-src https://cdn.jsdelivr.net https://fonts.gstatic.com;
