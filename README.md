# YVPlayer — Custom Player for YouTube Videos Without YouTube Elements &amp; Branding 🌐

> The cinema-grade, distraction-free HTML5 video player for YouTube videos without YouTube elements, logos, watermarks, or suggested watch-next overlays. Includes custom storyboard timeline scrub previews, 720p HD Picture-in-Picture, custom themes, line-by-line captions, and rich keyboard gestures.

## 📂 Demo Website Files
- `index.html` - Interactive Showcase page with quick sample presets, live customizer, and AI Prompt Architect.
- `app.js` - Showcase application script, quick samples handler, and Prompt Generator logic.
- `style.css` - Showcase UI styling and layout.
- `docs.html` - Complete documentation portal with search, architecture breakdown, and open-source stream proxy guides.
- `docs.js` - Documentation search, tabs, and interactive examples.
- `docs.css` - Notion-style documentation portal styling.
- `pip_embed.html` - Document Picture-in-Picture floating window embed.
- `yvPlayer.js` & `yvPlayer.css` - Core player library files.
- `tabler-icons.min.css` & `fonts/` - UI icon assets.
